# 다봐 / ohmyplayer — 현재 한계와 배포 범위

기준일: 2026-11-18 · Windows PoC 수정 빌드 `0.1.16`

이 문서는 첫 설치본을 정식 제품으로 오해하지 않도록 현재 구현 상태와 검증이 끝나지 않은 항목을 공개합니다.

## 지원 대상과 재생

- 현재 앱은 **Windows 10/11 x64 전용 WPF PoC**입니다. Android/iPhone용 앱은 아직 없습니다.
- LibVLC가 열 수 있는 컨테이너와 코덱을 사용하지만, 모든 MP4/ASF/WMV 파일이 재생된다고 보장하지 않습니다. 실제 파일의 코덱, 손상 여부, DRM, 하드웨어 디코더, PC 성능에 따라 달라집니다.
- 로컬 파일과 접근 가능한 HTTP/HTTPS 직접 미디어 주소를 지원합니다. YouTube, Vimeo, X, Instagram, Facebook, Threads 주소는 WebView2 창에서 서비스의 웹 플레이어로 엽니다. 사용자 로그인, 임베드 허용 여부, 지역·연령 제한 등 서비스 상태에 따라 재생이 제한될 수 있습니다.
- URL 파일 저장은 HTTP/HTTPS 직접 파일 주소만 지원합니다. 플랫폼 페이지에서 미디어 스트림을 추출하거나 저장하는 기능은 제공하지 않습니다. YouTube는 공식 정책상 사전 서면 승인 없는 다운로드/오프라인 재생을 금지합니다. Vimeo의 다운로드 가능한 파일 링크는 해당 영상 소유자의 설정과 API 권한에 따라 달라집니다.
- 플랫폼 웹 플레이어 기능에는 Microsoft Edge WebView2 Runtime이 필요합니다. 런타임이 없는 환경에는 별도 설치가 필요할 수 있습니다.
- 자막 파일 자동 검색, 외부 자막 열기, 내장 트랙 선택을 제공합니다. 설치·개발 패키지는 Whisper 실행 엔진, `small` 모델, FFmpeg를 함께 포함하도록 구성했습니다. CC 생성은 로컬 영상 전체를 먼저 처리한 뒤 재생하며, 영상 길이에 따라 준비 시간이 걸립니다. CC 생성은 자동 실행되지 않으며 재생창의 `CC 생성`을 눌러 시작합니다. 생성 처리는 PC에서 실행되고 영상·음성 파일을 번역 서버로 보내지 않습니다.
- SRT/VTT 자막은 같은 이름의 로컬 파일 자동 검색, 직접 연 파일, CC 생성 결과에 대해 설정에서 선택한 Ollama 로컬 모델 또는 Gemini API로 번역해 별도 자막 트랙으로 표시할 수 있습니다. 두 번역 방식은 동시에 켜지지 않습니다. 전체 파일을 먼저 번역하므로 자막이 길면 준비 시간이 늘어납니다. Ollama 번역은 PC에서 실행 중인 Ollama와 선택 모델이 필요하고 인터넷 API 요금은 없지만, 모델 크기와 PC 성능에 따라 느리거나 결과 형식이 맞지 않을 수 있습니다. Gemini 번역은 사용자가 발급한 API 키, 인터넷 연결, Google 사용량 한도가 필요합니다. 자막 글꼴·크기·굵기·외곽선은 재생 설정에서 바꿀 수 있습니다. 자막 읽기는 생성된 자막 또는 SRT를 Windows 음성으로 읽으며 품질과 언어는 설치된 음성에 따라 달라집니다. 웹·클라우드 영상과 내장 자막 트랙은 자동 번역되지 않습니다.
- Ctrl+C 또는 재생 창의 프레임 캡처 버튼은 현재 프레임을 PNG로 저장합니다. 첫 사용 때 저장 폴더를 선택하며 이후에는 설정에서 바꿀 수 있습니다.
- Ollama 텍스트 모델은 SRT/VTT 자막 번역에 연결됩니다. 선택된 모델이 음성 인식(ASR)을 지원한다고 가정하지 않습니다. 음성 전사는 포함된 Whisper 엔진, 음성 읽기는 Windows 음성 기능을 사용합니다. Gemini 번역은 SRT/VTT 텍스트에 한정되고 내장 자막, YouTube 등 웹 플레이어 자막, 클라우드/온라인 영상의 자막은 자동 번역하지 않습니다. Gemini 번역에는 사용자가 발급한 개인 API 키, 인터넷 연결, Google 사용량 한도가 필요합니다. 키는 DPAPI로 Windows 사용자 계정에 보호해 저장합니다. 자막 텍스트는 Gemini 요청에서 Google로 전송되며 영상/오디오는 전송하지 않습니다.

## 네트워크 저장소와 클라우드

- SMB/UNC와 WebDAV는 구현돼 있으나 서버별 인증·폴더 목록·탐색·seek 동작을 다양한 장치에서 검증해야 합니다. NFS는 미지원입니다.
- Google Drive, OneDrive, Dropbox의 PC 동기화 폴더는 탐색할 수 있습니다. 공급자 API를 통한 제품 로그인은 앱 등록·검증이 완료되지 않았으며 일반 배포에서 활성화하지 않았습니다.
- MYBOX는 사용자가 발급한 개인 액세스 토큰을 사용하는 경로입니다. 공유받은 폴더와 암호 폴더는 Open API에서 지원하지 않으며, MYBOX DRM 콘텐츠 재생도 검증되지 않았습니다.
- PikPak은 WebDAV 주소와 자격 증명으로 연결합니다. 연결 확인 후 메인 메뉴의 PikPak 항목에서 목록을 열 수 있습니다. Premium 계정의 공식 WebDAV 기능에 의존하며, 계정 쿼터·서버 정책·장시간 스트리밍·seek는 실계정별로 확인해야 합니다.

## 계정·AI 연동

- OpenAI Sign in with ChatGPT 상용 연동 관심 신청은 제출됐지만 승인되지 않았습니다. 앱에는 ChatGPT 요금제 연결이나 번역 요청 기능이 없습니다.
- Gemini API 호출은 사용자가 입력한 본인 API 키로 이루어지며 Google 사용량/요금 정책이 적용됩니다. PC 앱에서 사용 중 키가 메모리에 노출될 수 있으니 공유/조직 키 대신 개인 키를 사용해야 합니다.
- ChatGPT 로그인, 토큰 갱신·회수, 요금제 연결은 별도 심사와 구현이 필요합니다.

## 설치·업데이트·배포

- `0.1.0`은 WPF 진입점에서 메인 창을 열지 않아 설치 후 프로세스만 남고 UI가 표시되지 않는 결함이 있었습니다. `0.1.1`에서 메인 창을 명시적으로 시작하도록 수정했고 게시 폴더 실행 파일의 시작 화면을 확인했습니다. `0.1.0` 설치본은 자체 업데이트 화면까지 도달하지 못하므로 `0.1.1` 설치 파일로 수동 교체해야 합니다.
- 설치본은 Windows x64용이며 .NET 8 런타임과 LibVLC 네이티브 런타임을 자체 포함합니다. 설치 범위는 현재 사용자 계정입니다.
- 정식 설치본은 실행할 때마다 공개 GitHub 릴리스 피드를 확인합니다. 메인 화면의 `업데이트 확인`으로 수동 확인도 할 수 있습니다. 설치 파일을 릴리스에 게시해야 실제로 새 버전을 받을 수 있습니다.
- 첫 업데이트가 실제로 제공되려면 버전 태그로 빌드한 설치·업데이트 파일을 공개 릴리스에 게시해야 합니다. 저장소 코드만 갱신해도 설치된 앱은 바뀌지 않습니다.
- 현재 빌드는 코드 서명 인증서 없이 생성됩니다. Windows SmartScreen/Defender에서 게시자 확인 경고가 나타날 수 있습니다. 공개 배포 전에 코드 서명 인증서와 신뢰 가능한 배포 주체를 정해야 합니다.
- 이 저장소에는 아직 `LICENSE`가 없습니다. LibVLC 등 포함 의존성의 라이선스 고지, 재배포 의무, 코덱 특허·지역별 요건을 검토하기 전에는 상업 제품 또는 무제한 공개 배포로 표시할 수 없습니다.
- 이 첫 설치본은 검증용 공개 PoC 후보입니다. 저장소 연결, 로그인, 업데이트 서버 장애, 특정 미디어 파일에서의 동작은 보증하지 않습니다.
