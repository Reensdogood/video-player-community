# 다봐 / ohmyplayer 0.1.1

2026-11-17

## 수정 사항

- 설치 후 앱이 프로세스만 실행하고 창을 표시하지 않던 시작 오류를 수정했습니다. 업데이트 지원용 사용자 지정 WPF 진입점에서 `MainWindow`를 직접 열도록 했습니다.
- 0.1.0은 화면이 열리지 않아 앱 내부 업데이트 확인에 도달하지 못하므로, 해당 버전 사용자는 0.1.1 설치 파일을 다시 실행해 업데이트해야 합니다.

## 산출물

- 사용자별 설치: `funnet.ohmyplayer-win-Setup.exe`
- MSI 설치: `funnet.ohmyplayer-win.msi`
- 포터블: `funnet.ohmyplayer-win-Portable.zip`
- 파일 검증: `SHA256SUMS.txt`

## 검증 범위

Release 빌드가 성공했고, 설치 패키지의 게시 폴더에서 앱 시작 화면이 표시되는 것을 확인했습니다. 설치 프로그램을 실행해 덮어쓰기 업데이트하는 절차와 영상 재생은 아직 실기기에서 확인하지 않았습니다. 파일은 코드 서명되지 않았습니다.
