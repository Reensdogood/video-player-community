# 다봐 / ohmyplayer 0.1.15

## 수정 사항

- 재생 오류가 별도 모달 팝업으로 앱을 막지 않도록 바꾸고, 오류 안내를 재생창 안에 표시합니다. 오류 뒤에도 다른 파일 선택과 창 닫기를 계속 사용할 수 있습니다.
- 설정에서 선택한 Ollama 모델을 실제 SRT/VTT 자막 번역 요청에 연결했습니다. 번역 사용 여부와 언어를 선택하고, 짧은 번역 요청으로 연결을 확인할 수 있습니다.
- Ollama 로컬 번역을 켜면 Gemini 번역은 자동으로 꺼집니다. 두 번역 경로가 동시에 실행되지 않습니다.
- 같은 이름의 외부 자막, 직접 연 SRT/VTT, Whisper CC 생성 결과가 로컬/Gemini 번역 설정을 따르도록 했습니다.
- Whisper 음성 전사와 Windows 음성 읽기는 텍스트 LLM과 별도 기능으로 설정 안내에 표시합니다.

## 지원 범위

- Ollama 번역은 PC에서 실행 중인 Ollama와 선택된 텍스트 모델이 필요합니다. SRT/VTT 파일을 배치로 번역합니다.
- 음성 전사는 앱 패키지에 포함된 Whisper 실행 파일과 `small` 모델을 사용합니다. 재생창에서 `CC 생성`을 눌러 시작합니다.
- 로컬 번역의 품질과 속도는 선택한 모델과 PC 성능에 따라 다릅니다. 웹 영상이나 내장 자막 트랙은 자동 번역하지 않습니다.
