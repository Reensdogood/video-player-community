# 0.1.18

- WebDAV videos can be transcribed with the bundled Whisper engine. A temporary copy is downloaded only after the user chooses CC generation, then removed after transcription and optional subtitle translation.
- Generated WebDAV transcripts can be translated with the configured Ollama local model or Gemini setting.
- Added one-click Ollama installation and selection for TranslateGemma 12B (about 8.1 GB) and 4B (about 3.3 GB).
- Added download progress and automatic selection of the installed recommendation.
