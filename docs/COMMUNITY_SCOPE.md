# ohmyplayer Community 범위

## 포함 범위

- Windows 10/11 x64용 로컬 영상 플레이어와 재생목록
- 직접 HTTP/HTTPS 미디어 주소, 로컬 동영상에 함께 둔 자막, 내장 오디오·자막 트랙
- 로컬 영상의 오프라인 CC 생성과 자막 스타일 설정
- SMB/UNC, WebDAV, 동기화 폴더 기반의 클라우드 파일 탐색
- Windows 설치본의 공개 릴리스 업데이트 확인

## 서비스 제약

YouTube, Vimeo, X, Instagram, Facebook, Threads 페이지는 해당 서비스의 웹 플레이어로 엽니다. 서비스 로그인·지역·연령·삽입 정책에 따라 재생이 달라질 수 있습니다. 직접 파일 주소 외에는 플랫폼 영상을 추출하거나 저장하지 않습니다. DRM과 접근 제한을 우회하지 않습니다.

Google Drive, OneDrive, Dropbox의 계정 로그인은 제품 OAuth 앱 등록과 검증이 끝나기 전까지 제공되지 않습니다. Community 앱에서는 각 서비스의 PC 동기화 폴더를 선택해 파일을 탐색합니다. MYBOX Open API는 사용자가 발급한 개인 액세스 토큰을 사용하고 암호 폴더와 공유 폴더를 지원하지 않습니다. PikPak은 Premium WebDAV 경로를 사용합니다.

## 배포 전 확인

이 저장소에는 아직 최종 라이선스 선언, 코드 서명, 코덱 및 포함 런타임의 라이선스 검토가 완료되지 않았습니다. 사용 가능한 파일 형식은 LibVLC, 파일 손상, 코덱 구성, 하드웨어와 DRM 상태에 따라 다릅니다. 검증하지 않은 서비스 동작은 보장하지 않습니다.
