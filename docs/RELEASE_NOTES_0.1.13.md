# 다봐 / ohmyplayer 0.1.13

## Gemini API 안내

- 설정의 `번역 모델` 탭에서 한국어 단계형 Gemini API 키 발급 안내를 브라우저로 엽니다.
- 안내 페이지는 GitHub Pages에서 제공하며 Google 계정 로그인과 API 키 발급 공식 페이지로 연결합니다.
- 이 버전에도 Gemini 번역 API 호출은 포함되지 않습니다. 안내에 따라 발급한 키를 앱에 입력하거나 사용할 수 없습니다.

## 배포 파일

- 공식 배포 버전: `0.1.13`
- 변경 내용은 [Gemini API 연결 가이드](https://reensdogood.github.io/video-player-community/GEMINI_API_SETUP_GUIDE.html)에서도 확인할 수 있습니다.
