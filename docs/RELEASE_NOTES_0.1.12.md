# 다봐 / ohmyplayer 0.1.12

## 재생

- 영상이 끝난 뒤 재생 버튼이나 스페이스바를 누르면 같은 영상이 처음부터 다시 재생됩니다.
- 플레이어에서 `Ctrl+C` 또는 프레임 캡처 버튼으로 현재 화면을 PNG로 저장합니다. 저장 폴더를 설정에 기억합니다.
- 자막 글꼴, 크기, 굵기, 외곽선 설정을 추가했습니다.
- 플레이어 컨트롤을 어두운 반투명 오버레이로 정리했습니다.

## CC 자막

- 설치 파일에 Whisper 실행 엔진, `small` 모델, FFmpeg를 포함합니다. 사용자에게 Python이나 모델 경로를 지정하게 하지 않습니다.
- CC 생성은 전체 영상을 먼저 분석하고 자막을 붙인 뒤 재생합니다. 준비 시간은 영상 길이와 PC 성능에 따라 달라집니다.

## 업데이트

- 오래된 24시간 확인 캐시를 제거해 정식 설치 앱은 시작할 때마다 새 버전을 확인합니다.
- 메인 창에 수동 업데이트 확인 버튼을 추가했습니다.
- 실제 업데이트 수신은 릴리스 파일이 GitHub 릴리스에 게시되고 네트워크에 접근할 수 있을 때 동작합니다.

## 배포 파일

- 공식 배포 버전: `0.1.12`
- CC 엔진과 모델이 포함돼 설치 파일 크기가 크게 늘었습니다.
