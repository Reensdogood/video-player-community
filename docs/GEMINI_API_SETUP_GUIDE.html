Gemini API 키 발급 안내

Google 계정으로 AI Studio에 로그인하고, Gemini API 요청에 사용할 키를 발급하는 과정을 단계별로 안내합니다.

ⓘ
이 안내는 키 발급까지 도와줍니다. 현재 ohmyplayer PoC에는 Gemini API 키를 등록하거나 번역에 사용하는 기능이 아직 없습니다. 키를 앱이나 이 페이지에 붙여 넣지 마세요. 이 페이지는 진행 체크만 저장하며 키와 계정 정보를 저장하지 않습니다.

준비 · 1단계

계정과 프로젝트를 준비하세요

Gemini API 키는 Google 계정의 AI Studio와 Google Cloud 프로젝트에 연결됩니다. 조직 계정이면 프로젝트 권한과 관리 정책을 먼저 확인하세요.

시작하기 전에

  • 사용할 Google 계정으로 로그인할 수 있는지 확인합니다.
  • 기존 Cloud 프로젝트가 있으면 어느 프로젝트에서 사용량과 권한을 관리할지 정합니다.
  • Google Cloud 프로젝트마다 사용량과 결제 설정이 달라질 수 있으므로 개인용/조직용 프로젝트를 구분합니다.
API 키는 비밀번호처럼 취급하세요. 다른 사람에게 보내거나 Git 저장소, 공개 문서, 스크린샷에 넣지 마세요.

로그인 · 2단계

Google 계정으로 AI Studio에 로그인

공식 AI Studio 페이지를 새 탭에서 열어 로그인하고 서비스 약관을 확인합니다.

진행할 일

페이지에서 사용할 Google 계정을 선택하고 안내되는 약관 확인을 마칩니다. ohmyplayer 계정이나 개발자용 OAuth Client ID를 만들 필요는 없습니다. 이 가이드는 Gemini API 키 발급을 안내합니다.

AI Studio 로그인 ↗
인증 범위: 여기서 로그인하는 것은 Google AI Studio 계정입니다. 이는 ohmyplayer에 Google Drive 같은 클라우드 파일 권한을 주는 것과는 별개입니다.
프로젝트 · 3단계

API 키를 연결할 프로젝트 선택

모든 Gemini API 키는 Google Cloud 프로젝트에 연결됩니다. 프로젝트가 사용량·권한·결제 설정을 관리합니다.

새 계정이라면

AI Studio가 기본 프로젝트를 준비할 수 있습니다. 프로젝트 이름을 확인하고 개인용 또는 조직용으로 알맞은지 살펴보세요.

기존 프로젝트를 쓰려면

AI Studio의 왼쪽 메뉴에서 Dashboard → Projects → Import projects를 선택해 프로젝트를 가져온 다음, 해당 프로젝트를 키 발급에 사용합니다.

AI Studio 프로젝트 메뉴 열기 ↗
키 생성 권한이 없다는 메시지가 나오면 프로젝트 관리자에게 IAM 권한을 확인해 달라고 요청하세요. 조직 정책이 있는 프로젝트는 관리자의 승인이 필요할 수 있습니다.
발급 · 4단계

Gemini API 키 만들기

AI Studio의 키 페이지에서 프로젝트를 선택하고 새 키를 발급합니다.

순서

  1. API Keys 페이지를 엽니다.
  2. Create API key를 선택합니다.
  3. 앞 단계에서 선택한 Google Cloud 프로젝트를 지정합니다.
  4. 생성이 끝나면 키가 표시되는 동안 안전한 비밀번호 관리 도구에 저장합니다.
API Keys 페이지 열기 ↗키 보안 공식 안내 ↗
2026년 5월 28일부터 AI Studio에서 새로 만든 키는 기본적으로 Gemini API 전용 authorization key입니다. 이전 standard key를 쓰고 있다면 공식 안내에서 제한/전환 방법을 확인하세요. 현재 생성 화면이 문서와 다르면 AI Studio의 안내를 우선하세요.
보관 · 5단계

키를 안전하게 보관하고 사용량 확인

이 단계에서는 발급한 키를 복사해 보내거나 가이드에 입력하지 않습니다. 키 발급 화면을 닫기 전에 안전한 보관 위치를 확인하세요.

키 보안

  • 키를 공개 저장소, 메신저, 이메일, 채팅에 붙여 넣지 않습니다.
  • 화면을 공유하거나 스크린샷을 올릴 때 키가 보이지 않게 합니다.
  • 의심스러운 노출이 있으면 AI Studio에서 해당 키를 폐기하고 새 키를 만듭니다.

사용량과 결제

무료 사용 가능 여부와 한도는 프로젝트/계정 조건에 따라 다를 수 있습니다. 한도를 높이기 위해 결제를 설정하기 전에 Google의 현재 가격 및 한도를 확인하세요.
