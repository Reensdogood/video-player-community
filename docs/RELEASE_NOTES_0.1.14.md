# 다봐 / ohmyplayer 0.1.14

## Gemini API 자막 번역

- 설정에서 Gemini API 번역을 켜거나 끌 수 있습니다.
- API 키, Gemini 모델, 대상 언어를 지정하고 연결을 확인할 수 있습니다.
- 같은 이름의 SRT/VTT, 직접 연 SRT/VTT, CC 생성 SRT의 전체 구간을 Gemini로 번역해 별도 자막 트랙으로 추가합니다. 원본 자막은 유지됩니다.
- API 키는 Windows 사용자 계정 DPAPI로 보호해 저장합니다. 번역 시 자막 텍스트만 Google에 전송하며 영상/오디오는 보내지 않습니다.
- 긴 자막은 여러 요청으로 번역하므로 Google API 사용량과 처리 시간이 증가할 수 있습니다.

## 현재 범위

- 내장 자막 트랙, 웹 플레이어 자막, 온라인 영상 자막은 번역하지 않습니다. 로컬 SRT/VTT 자막에 사용하세요.
- Gemini 연결은 사용자가 발급한 개인 API 키와 인터넷 연결을 필요로 합니다. 키 입력/연결 확인은 Google 사용량을 발생시킬 수 있습니다.
