# Video Player Community

Windows-first video player project. The first delivery target is a Windows proof of concept; Android and iOS are later product targets.

Repository: https://github.com/Reensdogood/video-player-community

## Community scope

- Local media playback and playlists
- Direct, accessible, non-DRM media URLs
- Basic audio/subtitle track selection and external subtitles
- Community provider interfaces for media sources and language models

## Pro boundary (not included here)

Cloud-drive connectors, expanded model providers, managed translation/TTS quotas, and commercial support are Pro candidates. They will live behind a separately licensed extension or service boundary. This repository will not contain secrets, customer tokens, or DRM circumvention code.

The exact Community/Pro feature split, license, and public release policy are still under review. A public repository exposes every file committed to it; it cannot hide selected files or source code.
